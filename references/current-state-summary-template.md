# 现状业务逻辑摘要模板

本模板用于在“基于现有 PRD / 历史方案 / 流程说明撰写新 PRD”时，先抽取当前业务逻辑，再进入新需求写作。

## 使用原则
- 本模板是 **中间分析产物**，用于帮助理解现状。
- 本模板内容 **不得与最终新 PRD 正文混写**。
- 若用户未要求展示中间分析过程，可在内部使用本模板完成理解后，直接输出独立的新 PRD。
- 若用户要求展示，则应明确分成两段：
  1. 现状业务逻辑摘要
  2. 新 PRD 正文

## 5. 输出新 PRD 前的写作提醒
- 新 PRD 必须是 **独立成文** 的完整文档。
- 参考 PRD 只能作为背景输入，不可与新 PRD 合并输出。
- 新 PRD 中若需提及现有业务逻辑，应采用“当前业务逻辑说明 / 与现状关系 / 改动点说明”的方式简要写入，而不是粘贴参考 PRD 原文。
- 若参考 PRD 与当前需求存在冲突，应在“待确认项”中指出，不要擅自合并。
