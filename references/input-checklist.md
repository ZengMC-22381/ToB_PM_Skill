# 输入收集清单

当用户要生成 PRD 时，优先收集以下信息：

## A. 基础信息
- 需求主题
- 需求来源
- 面向对象 / 用户角色
- 当前所处业务场景

## B. 问题与目标
- 当前痛点是什么
- 为什么现在要做
- 希望达成什么结果

## C. 范围信息
- 本期要做什么
- 本期不做什么
- 是否已有初步方案

## D. 约束信息
- 时间限制
- 技术限制
- 跨团队协同限制
- 是否依赖其他系统 / 模块

## E. 补充材料
- 会议纪要
- 竞品截图
- 现有页面
- 原型稿
- 历史 PRD


## F. 现有业务逻辑材料（如有）
- 现有 PRD / 历史版本文档
- 现有流程图 / 会议纪要
- 现有角色权限说明
- 现有实体关系 / 数据结构说明
- 本次明确不改动的范围
